# 飛資得講習站｜第 1 階段驗收清單

部署完成（SETUP.md 步驟 1～7）後逐條測試。每一條都寫了「怎麼做」和「應該看到」。
建議先在後台建一堂「驗收測試」課程，設兩個獎項（例：A 獎 × 2、B 獎 × 1），開放填答。

先跑一次 **runSelfTest**（後台 Apps Script → 選 runSelfTest → 執行），41 項全部 ✅ 再開始手動測試。
自我測試已經用真的公開 API 驗過：輸入驗證、遮罩、公式注入、Email 重複、抽獎不重複、清除資料。下面是要用你自己的眼睛確認的部分。

---

### 1. 用手機掃 QR Code，1 分鐘內完成問卷與抽獎登記

- 怎麼做：課程詳情按「開啟投影畫面」，手機掃 QR Code，填完 4 題必填 → 送出 → 我要參加抽獎 → 姓名、Email、勾同意 → 確認登記。計時。
- 應該看到：進度條隨著作答增加；送出時按鈕下沉、出現三顆跳動的小圓點；完成頁勾勾畫出來、旁邊橘點彈一下；最後顯示「登記完成！」。全程不到 1 分鐘。

### 2. 同一堂課用同一 Email 登記第二次會被拒絕，並顯示友善訊息

- 怎麼做：換一支手機（或用無痕視窗打開問卷網址），再填一次問卷，抽獎時輸入**同一個 Email**，可以故意改大小寫（例 `Emily@Gmail.com`）。
- 應該看到：紅字「這個 Email 已經登記過這堂課的抽獎囉，不用再登記一次。」，資料沒有新增。

### 3. 課程未開放或已結束時，問卷頁顯示對應狀態且無法送出

- 怎麼做：
  1. 建一堂新課程（草稿），在課程詳情按「預覽問卷 ↗」。
  2. 回到驗收課程，按「結束填答」，再用無痕視窗打開它的問卷網址。
  3. 在某支手機上先打開問卷但不送出，講師按「結束填答」後，手機才按送出。
- 應該看到：1 →「問卷尚未開放」；2 →「問卷已截止」；3 → 送出後畫面變成「問卷已截止」，資料沒有寫入。
- 測完把驗收課程按「重新開放填答」（還沒抽獎前才能重新開放）。

### 4. 投影畫面數字在 15 秒內反映新回覆

- 怎麼做：投影畫面開著，手機送出一份問卷，開始計時。
- 應該看到：15 秒內「份課程回饋」加 1，數字有往上翻的動畫；下方「每 15 秒自動更新・HH:MM 更新」的時間跟著變。

### 5. 不登入 Google 開啟後台網址會被拒絕

- 怎麼做：用無痕視窗（或另一個 Google 帳號）打開後台網址。
- 應該看到：Google 登入畫面，或「很抱歉，您沒有權限」之類的錯誤頁，看不到任何課程資料。投影頁的「講師抽獎」按鈕在無痕視窗點下去也一樣被擋。

### 6. 在開發者工具搜尋公開頁面程式碼，找不到可讀取姓名或 Email 的方法

- 怎麼做：電腦用 Chrome 打開問卷頁 → 右鍵「檢查」→ 上方 **Sources**，看 `s/index.html`、`live/index.html`、`assets/app.js`；按 **⌘ + Option + F** 搜尋 `email`。
- 應該看到：只有「送出抽獎登記」會用到 email（寫入），沒有任何讀取名單的呼叫。公開 API 只有五個動作：getSurvey、submitResponse、registerRaffle、getLive、getViewer，回傳都沒有姓名或 Email。
- 加碼檢查：打開 `gas-public/Code.gs`，抽獎分頁只讀 `course_id`、`email_hash`、`prize` 三欄。

### 7. 未結束填答時無法抽獎；重新整理抽獎畫面不會重抽；同一人不會中兩次

- 怎麼做：
  1. 填答還開著時，投影畫面點「講師抽獎」。
  2. 按「結束填答並凍結名單」→ A 獎「抽出下一位」抽 1 位。
  3. 按瀏覽器的重新整理。
  4. 把 A 獎抽滿、切到 B 獎抽完。
  5. 打開試算表 `raffle_entries`，看 prize 欄。
- 應該看到：1 → 顯示「填答還在進行中」，沒有抽獎按鈕；2 → 問號卡片翻成票券、姓名一個字一個字彈出，只顯示遮罩後的姓名與 Email（王○明、mi\*\*\*@gmail.com）；3 → 已抽出的人還在，沒有多抽；4 → 獎項抽滿後按鈕變成「這個獎項已抽滿」；5 → 每個人最多只有一個獎項。
- 小技巧：用簡報筆的「下一頁」鍵也可以抽。

### 8. 在文字題輸入 `=1+1`，試算表顯示的是文字而非算式結果

- 怎麼做：問卷最後一題輸入 `=1+1` 送出；抽獎姓名也輸入 `=1+1` 登記。打開試算表 `responses` 與 `raffle_entries`。
- 應該看到：答案欄是一段文字（含 `=1+1`），抽獎的姓名欄顯示 `=1+1`，**不是 2**。點那一格，上方公式列也是 `=1+1` 文字。

### 9. 「清除本堂抽獎資料」後，試算表內該課已無任何姓名與 Email

- 怎麼做：課程詳情 →「匯出名單 CSV」（確認檔案能打開、中文正常）→「清除本堂抽獎資料」→ 輸入「清除」→ 永久清除。打開試算表 `raffle_entries`，用 course_id 篩選。
- 應該看到：這堂課一筆都沒有；課程詳情「抽獎名單」改成「已於…清除…保留統計：登記 N 人、得獎 N 人」；`audit_log` 有一列 `clear_raffle`。

---

### 簡報（提前自第 2 階段）

- 怎麼做：課程詳情「課堂簡報」選 Canva 嵌入，貼 Canva 的嵌入程式碼（或檢視連結）→ 套用；再試 PDF 連結貼雲端硬碟分享連結。按「開啟檢視頁 ↗」。
- 應該看到：課程詳情立刻出現預覽；檢視頁簡報佔滿畫面，可以用 Canva 自己的箭頭翻頁；按「顯示回饋 QR」跳出大 QR Code，按 × 或空白處關閉。課程還是草稿時，檢視頁一樣看得到簡報。
- 貼 Canva 的編輯連結應該被拒絕，並說明要改用「分享 → 更多 → 嵌入」。

### 額外確認（不在驗收標準裡，但上線前值得看一次）

- 後台「複製連結」「下載 QR」在你的 Chrome 能正常運作（Google 後台頁面是包在框架裡的，少數瀏覽器設定會擋下載，遇到請告訴 Claude）。
- 下載的 QR PNG 印出來或貼到簡報，用手機掃得到。
- 平板寬度打開後台，側欄收到上方。
- 手機開「減少動態效果」（iPhone：設定 → 輔助使用 → 動作），動畫會關掉。
